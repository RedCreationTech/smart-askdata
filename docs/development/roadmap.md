# 开发路线图

## Phase 0 技术验证

目标:

- 完成 ClojureScript React 基础工程
- 完成数据库连接验证
- 完成 QueryPlan 原型
- 完成模型调用链

## Phase 1 MVP

范围:

- 用户问数工作台
- PostgreSQL/MySQL 接入
- 指标定义
- Schema 解析
- SQL生成与执行
- 图表展示

验收:

20 个标准问题端到端闭环。

## Phase 2 Semantic Layer

增加:

- 知识图谱
- 指标管理
- 业务实体
- 字段映射
- 同义词管理

## Phase 3 RAG 与知识学习

增加:

- 文档解析
- Embedding
- Hybrid Retrieval
- 反馈闭环
- 知识审核发布

## Phase 4 企业化

增加:

- 数据权限
- 审计
- 私有化部署
- 多租户
- 高可用

## 开发规范

所有功能必须包含:

1. 设计文档
2. API契约
3. 数据模型
4. 自动测试
5. Demo数据
6. 验收案例
